# 来裁（ImageBorderCrop）

“来裁”是一款 Android 图片与 GIF 智能去边工具——自动检测并裁剪图片四周的纯色边框，也能从带状态栏、按钮和留白的截图中提取主要图片区域。
下载的表情包、传送门获取的图片或应用截图，经常带有黑白边框及界面留白，可以用这个工具快速识别并裁剪。

## 功能

- **自动检测** — 置入图片或调整强度后自动识别纯色边框，结果可疑时进一步寻找截图中的主要矩形内容
- **逐行/列扫描** — 精确检测上下左右四边的纯色边框宽度
- **截图取图** — 通过缩略图分块、长直边界、内容活跃度和中心位置加权，过滤状态栏、图标和按钮
- **GIF 动图** — 动态预览原图和裁剪结果，逐帧取安全裁剪范围，保存时保留动画、帧时长、循环和透明背景
- **强度调节** — 通过滑块控制颜色容差，适应不同场景
- **手动边界微调** — 点击检测结果，通过四侧滑块快速定位，并用 − / + 步进器进行 1px 精调
- **后台检测** — 大图检测在后台线程运行，避免阻塞界面
- **最近图片快捷入口** — 授权图库后显示最新图片缩略图，点击即可直接载入；Android 14 支持仅访问选定照片
- **Edge-to-Edge** — 内容背景延伸到系统栏，并自动避让状态栏、刘海和底部手势提示线
- **系统分享入口** — 从其他 App 分享图片进来直接处理
- **格式保持** — 支持 JPG/PNG/WEBP/GIF，保存时保持原格式

## 使用方式

1. 点击首页的最近图片缩略图快速载入，或点击「选图」从相册选择图片，也可从其他 App 分享图片到本应用
2. 应用会自动检测并预览裁剪结果；需要时可调节强度，调整后自动重新检测
3. 如需修正边界，点击「边框信息」打开手动调整面板
4. 点击「裁剪保存」导出

## 核心算法

- `BorderDetector.kt`：纯色边框扫描、自动结果校验与检测策略选择
- `ContentRegionDetector.kt`：纯 Kotlin 的缩略图分块、长直边界候选、矩形评分和原图边界吸附
- `GifProcessor.kt`：GIF 校验、逐帧解码、安全范围合并和动画重编码

自动模式优先使用纯色边框结果；当结果为空、只识别到单侧边框，或裁剪后仍存在多侧同色空白时，才启用主要内容区域检测。强度滑块只影响黑边/白边判断，内容区域检测使用自适应统计。

GIF 会分析每一个完整合成帧，并且只裁掉所有帧都确认属于边框的区域。逐帧阶段使用轻量的边缘占比扫描，能忽略调色板抖动和低亮度残留像素；检测到黑边中的高对比字幕或其他有效内容时会保留该侧。首帧、50% 帧和末帧还会运行主要内容区域校验，只有至少两个代表帧给出稳定的内部边界时才限制纯色结果，并且绝不会突破全帧安全范围增加裁剪量。处理时间仍会随分辨率和帧数增加，保存期间会显示编码帧进度。为避免异常文件导致长时间卡顿，单个 GIF 限制为 100 MiB、最长边 8192 px、最多 500 帧、单帧不超过 4000 万像素且累计不超过 2.5 亿像素。GIF 重编码受 256 色格式限制，输出可能出现轻微色差或比原文件更大。
