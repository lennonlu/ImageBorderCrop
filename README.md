# 来裁

“来裁”是一款简单易用的 Android 图片去边工具，可以自动裁掉图片或 GIF 四周多余的黑边、白边和页面留白。

无论是传送门保存的图片、下载的表情包、带边框的动图，还是包含状态栏和操作按钮的应用截图，都可以用“来裁”快速整理后保存到相册。

## 主要功能

- 自动识别并裁剪图片四周的多余边框
- 支持从应用截图中提取主要图片区域
- 支持 GIF 动图裁剪
- 提供强度调节，适应不同深浅的黑边或白边
- 支持手动微调上、下、左、右四个裁剪边界
- 支持从其他应用直接分享图片到“来裁”

## 使用方法

1. 点击“选图”，或使用最近图片，或从其他应用分享图片到“来裁”。
2. 图片载入后会自动检测并显示裁剪结果。
3. 如有需要，可以调整“强度”，或点击“边框信息”手动微调四边。
4. 确认预览后，点击“裁剪保存”即可保存到相册。

## 支持格式

- JPG / JPEG
- PNG
- WebP
- GIF

GIF 的处理时间会随图片尺寸和帧数增加，保存时请耐心等待完成提示。

## 隐私

所有图片检测和裁剪均在设备本地完成，不会上传到网络。

图库权限仅用于显示和快速选择最近图片；也可以只使用系统选图器或分享入口。
